# 🚗 자동차 경주

## 구현 기능 목록

### 입력 기능 구현
* [x] 경주에 참여할 자동차 이름을 입력받는다. (이름은 쉼표(,) 기준으로 구분)
* [x] 시도할 횟수를 입력받는다.

### 자동차 이름 저장 기능 구현
* [x] 입력받은 자동차 이름들을 쉼표(,) 기준으로 자른다.
* [x] 분리된 자동차 이름들을 리스트에 저장한다.

### 자동차 기능 구현
* [x] 자동차는 이름과 위치를 가진다.
  * [x] 자동차 이름이 5글자를 넘어가는 경우 예외가 발생한다.
* [x] 자동차는 전진하는 기능을 가진다.
  * [x] 0부터 9 사이의 무작위 값이 4 이상이면 자동차 위치를 증가시킨다.
  
### 자동차 객체 저장 기능 구현
* [x] 입력받은 자동차 이름들로 자동차 객체를 생성한다.
* [x] 생성된 자동차 객체들을 리스트에 저장한다.
* [x] 랜덤 숫자에 따라 경주에 참여하는 자동차가 동시에 전진한다.

### 시도 횟수 숫자 변환 기능 구현
* [x] 입력받은 시도 횟수를 숫자로 변환한다.
  * [x] 입력값이 공백일 경우 예외가 발생한다.
  * [x] 시도 횟수가 1보다 작은 경우 예외가 발생한다.
  * [x] 시도 횟수가 숫자가 아닐 경우 예외가 발생한다.

### 자동차 이름 예외 기능 구현
* [x] 입력값이 공백일 경우 예외가 발생한다.
* [X] 자동차 이름이 문자가 아닐 경우 예외가 발생한다.
* [x] 입력값이 쉼표(,)로 끝나는 경우 예외가 발생한다.
* [x] 경주에 참여할 자동차가 2대 미만일 경우 예외가 발생한다.

### 경주 기능 구현
* [x] 저장된 자동차들을 불러온다.
* [] 저장된 자동차들로 경주를 진행한다. 
* [] 이동 결과를 자동차 이름과 이동 거리('-' 표시) 형태로 결과 리스트에 저장한다.

### 우승자 발표 기능 구현
* [] 전체 자동차 중에서 가장 멀리 이동한 거리를 구한다.
* [] 최대 이동거리를 가진 자동차들의 이름을 우승자 리스트에 저장한다.

### 출력 기능 구현
* [] 경주 결과를 출력한다.
* [] 가장 많이 이동한 자동차 이름을 쉼표(,)로 구분하여 출력한다.
